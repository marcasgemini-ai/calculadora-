# Bronzer · DR WOMAN: 12 estáticos con el producto como protagonista (1:1)

**Formato:** todos cuadrados **1:1 · 1080×1080**.
**Cambio de enfoque:** el **frasco es el protagonista** y ocupa entre el 40 y el 60 % de la imagen. Cada anuncio tiene un **diseño de anuncio armado** (grilla, jerarquía, íconos, llamados), como los de las marcas DTC premium, no una foto con texto encima.
**Siempre presente:** la palabra **BETACAROTENO** y el resultado deseado: *dorada, pareja, sin sol*.

---

## Lo más importante: que el frasco salga perfecto

ChatGPT tiende a **redibujar la etiqueta**. Para que el producto quede impecable:

1. **Foto del frasco de buena calidad**: de frente, con fondo liso, bien iluminada, sin reflejos y en alta resolución. Si la foto es mala, el anuncio sale mal. Es lo que más influye en el resultado.
2. Adjuntala **siempre como primera imagen** del chat y el logo como segunda.
3. Si la etiqueta sale deformada (pasa seguido), usá el **método de 2 pasos**, que es el que usan las diseñadoras:
   - **Paso 1:** pedí el mismo prompt agregando al final: `Leave the bottle area empty: same scene, same shadow and lighting, but without the bottle.`
   - **Paso 2:** en **Canva** o Photoshop, pegá tu **PNG real del frasco sin fondo** en ese lugar, con una sombra suave. Queda 100 % fiel y nadie nota el montaje.
4. Frases para corregir:
   - Frasco deformado: `Keep everything identical, only replace the bottle with the exact bottle from image 1, same size and position`.
   - Texto mal escrito: `Keep everything identical, only fix the text so it reads exactly: "…"`.
