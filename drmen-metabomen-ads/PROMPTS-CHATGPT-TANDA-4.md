# Metabomen Ads · Batch 4 · ChatGPT image prompts (English)
Ángulo 100% envejecimiento / verse y sentirse más joven. Cuadrado 1:1. Sin oferta.

## Paso a paso (igual para los 3)
1. Abrí un **chat nuevo** en ChatGPT por cada anuncio.
2. Adjuntá **2 archivos**:
   - **Archivo A · Frasco:** foto del frasco Metabomen de frente, bien iluminada (ideal PNG con fondo blanco o transparente).
   - **Archivo B · Referencia:** la captura del anuncio que replicamos. Solo es guía de diseño.
3. Pegá el prompt completo y enviá.
4. Si un texto sale mal: `Fix only the text "..." so it reads exactly "...". Keep everything else identical.`
5. Si el frasco sale distinto: `Replace the bottle with the exact bottle from the first image I attached. Same label, same proportions. Keep everything else identical.`
6. Si la imagen sale vertical: `Make it a perfect square 1:1, 1080x1080, keep the same composition.`

## Qué cambié respecto de las referencias
- **Ad 16:** la reseña tiene que ser real. ChatGPT inventaría una si no se la das.
